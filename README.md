# CoRoute AI Pool

Prototype HTML de covoiturage optimisé par intelligence artificielle.

## Fichiers

- `driver.html` — Vue conducteur avec faux plan, paramètres d'optimisation IA, informations de trajet et sélection des passagers. Départ depuis **Marcoussis**.
- `passenger.html` — Vue passager (interface mobile) avec carte, infos conducteur, liste des arrêts et confirmation de correspondance.

## Utilisation

Ouvrir directement dans un navigateur — aucune dépendance, tout est autonome.

## Contexte

Projet TIPE — Covoiturage intelligent avec optimisation IA du remplissage véhicule.
